# Changelog

## 0.1.0-alpha — 2026-09-03

### Adicionado
- estrutura inicial Windows + Android;
- interface visual PCFlow em grafite/dourado/turquesa;
- descoberta automática em rede local;
- pareamento por PIN e dispositivo autorizado;
- touchpad remoto;
- teclado remoto e texto Unicode;
- comandos de mídia;
- comandos de energia;
- bandeja do sistema no Windows;
- foreground service no Android;
- reconexão automática com backoff;
- configuração de fechamento para bandeja;
- CI para build Windows e APK Android.
